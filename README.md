# Survival Analysis Script

This repository contains the files needed for a survival analysis in R related to the results obtained in this study (https://doi.org/10.1155/vmi/1271185).

## Files

- Survival_analysis.R: The analysis script.

- Supplementary_data.xlsx: The raw data.

## Setup

You need R and these packages installed:

tidyverse, readxl, survival, survminer, psych

## Run the Analysis

1. Put both files (.R and .xlsx) into one folder.

2. Open Survival_analysis.R in RStudio.

3. Run the entire script.

**The results (plots and model summaries) will be displayed in your R environment.**
